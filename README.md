# Computer-e

دليل عربي تفاعلي للاستفادة من خدمات GitHub المجانية، مع إعداد عملي للنشر والاختبارات والأمان. موقع ثابت، متجاوب، يدعم RTL والوضع الداكن، ولا يحتاج خادمًا أو بطاقة بنكية للنشر على GitHub Pages من مستودع عام.

> **ملفات الإعداد جاهزة، لكن هذا ليس تأكيدًا بأن الموقع منشور.** يحتاج مالك المستودع إلى اختيار **GitHub Actions** في إعدادات Pages ودمج الملفات في `main`. لا تعتبر النشر مكتملًا إلا بعد نجاح مهمة `deploy`.

**الرابط المتوقع بعد نجاح النشر:** https://celiaelazamey-arch.github.io/Computer-e/

## ما الذي أُضيف؟

| الميزة     | الموجود في المستودع                         | ما يحتاج تفعيلًا من الحساب؟                       |
| ---------- | ------------------------------------------- | ------------------------------------------------- |
| Pages      | موقع HTML/CSS/JS وسير عمل `Deploy Pages`    | اختيار مصدر Pages ثم الدمج في `main`              |
| Actions    | اختبارات وحدات، اختبارات متصفح، بناء ونشر   | السماح بتشغيل Actions حسب سياسة الحساب            |
| الأمان     | CodeQL، Dependabot، سياسة أمان              | مراجعة تنبيهات التبعيات وفحص الأسرار وحماية الرفع |
| Codespaces | ملف `.devcontainer/devcontainer.json`       | اختيار جهاز ثنائي النواة وإنشاء البيئة عند الحاجة |
| Packages   | Dockerfile ونشر GHCR **يدوي اختياري**       | تشغيله فقط عند الحاجة ومراجعة ظهور الحزمة         |
| Projects   | قوالب Issues وPull Requests ودليل لوحة مهام | إنشاء لوحة في حسابك وربطها بالمستودع              |
| Copilot    | تعليمات Free وStudent وروابط رسمية          | تفعيل شخصي؛ لم يتم إنشاء اشتراك                   |
| Skills     | روابط ودليل الدورات المجانية                | بدء الدروس باختيارك                               |

لم يُنشأ Codespace، ولم تُنشر حزمة، ولم تُغيَّر الفوترة أو وسيلة الدفع أو نوع خطة الحساب.

## النشر المجاني — بدون فيزا

1. افتح [Settings → Pages](https://github.com/celiaelazamey-arch/Computer-e/settings/pages)، واختر **GitHub Actions** من **Source**.
2. راجع طلب الدمج من فرع `arena/01a0f844-computer-e` إلى `main` وادمجه من واجهة GitHub.
3. تابع [Actions → Deploy Pages](https://github.com/celiaelazamey-arch/Computer-e/actions/workflows/pages.yml). النشر يعمل تلقائيًا عند تحديث `main`، ويمكن تشغيله يدويًا بعد الدمج.
4. بعد نجاح `deploy`، افتح الرابط الذي يعرضه GitHub. إذا دُمجت الملفات قبل تفعيل Pages، شغّل السير يدويًا مرة أخرى من `main`.

**لا تنشئ فرع `gh-pages`، ولا ترفع `dist` إلى Git.** سير العمل يبني ويرفع ملفات الموقع فقط. لا تحتاج نطاقًا مدفوعًا أو أسرارًا شخصية؛ النشر يستخدم `GITHUB_TOKEN` المؤقت.

التفاصيل وحلول الأخطاء: [دليل التفعيل](docs/ACTIVATION.md).

## التشغيل محليًا أو في Codespaces

يتطلب Node.js 22 أو أحدث. لا توجد تبعيات تشغيل للموقع؛ الحزم الموجودة أدوات اختبار فقط.

```sh
npm ci --ignore-scripts
npm run check
npm run dev
```

الخادم يستمع على `0.0.0.0:3000` ويقبل مضيف المعاينة وCodespaces. في Codespaces افتح المنفذ 3000. ملفات الموقع تستخدم مسارات نسبية، وتعمل على `/Computer-e/` وعلى جذر خادم ثابت.

لرؤية النسخة المبنية:

```sh
npm run build
npm run preview
```

### اختبارات المتصفح وإمكانية الوصول

```sh
npx playwright install --with-deps chromium
npm run test:browser
```

تُختبر التصفية والبحث العربي والنوافذ وقائمة المتابعة والنسخ والوضع الداكن، والهواتف والشاشات الكبيرة، ومسار GitHub Pages، وعدم الاعتماد على JavaScript لقراءة المحتوى. تفحص axe معايير WCAG الأساسية؛ الاختبارات الآلية لا تغني عن مراجعة بشرية لإمكانية الوصول.

## إعدادات GitHub من حساب المالك

يتطلب الأمر GitHub CLI (`gh`) متصلًا بحساب له صلاحيات إدارة المستودع. **لا تشارك كلمات مرور أو رموز وصول في المحادثة أو الملفات.**

```sh
npm run github:check  # قراءة الحالة فقط، دون تغييرات
npm run github:setup # تفعيل Pages وبعض إعدادات الأمان، بعد التحقق من الصلاحيات
```

السكربت لا يغيّر المستودع إلى عام، ولا يعدّل سياسة Actions أو الفوترة، ولا ينشئ Projects أو Codespaces أو اشتراك Copilot. يتوقف إذا كان المستودع خاصًا أو لم تتوفر صلاحية الإدارة. يمكن تنفيذ الخطوات نفسها يدويًا من [دليل التفعيل](docs/ACTIVATION.md).

## تنبيهات مهمة

- GitHub Pages تستضيف مواقع ثابتة فقط، وليست Backend أو قاعدة بيانات أو خدمة لاستضافة متجر إلكتروني.
- وقت مشغّلات Actions القياسية مجاني للمستودعات العامة؛ لا يعني ذلك إلغاء حدود التشغيل أو التخزين أو الاستخدام العادل. تتوقف وظائف هذا الإعداد إن أصبح المستودع خاصًا لتجنب تشغيل مدفوع غير مقصود.
- حصة Codespaces للحساب الشخصي Free هي **120 ساعة نواة**، أي نحو **60 ساعة** على جهاز ثنائي النواة، و**15 GB-month** تخزين. الإيقاف لا يحذف التخزين.
- بدون وسيلة دفع، يتوقف Codespaces وPackages عند نفاد الحصة. إذا كان حسابك يحتوي على وسيلة دفع أصلًا، راجع ميزانيات الإيقاف؛ السكربت لا يفحصها أو يعدّلها.
- قائمة المتابعة على الموقع شخصية ومحلية؛ لا تستعلم من GitHub ولا تثبت تفعيل أي ميزة.
- لم نضف تحليلات أو طلبات إلى خطوط خارجية. خطوط IBM Plex Sans Arabic مرفقة وفق [SIL OFL](site/fonts/LICENSE.txt). يستمر تسجيل عناوين IP المعتاد لدى GitHub Pages حسب سياسة GitHub.
