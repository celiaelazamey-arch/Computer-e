# موارد GitHub المجانية — دليل محدَّث

**آخر مراجعة للتوثيق الرسمي: 1 أكتوبر 2026.**

الأرقام للحسابات الشخصية على **GitHub Free** ما لم يُذكر غير ذلك. قد تتغير السياسات؛ صفحة الخدمة وحالة حسابك هما المرجع النهائي.

## المسار الذي لا يحتاج بطاقة

لهذا المستودع العام، نستخدم **GitHub Pages** للموقع الثابت و**GitHub Actions على Ubuntu القياسي** للاختبار والبناء والنشر. النطاق الافتراضي `github.io` مجاني. لا نفعّل خدمة مدفوعة أو نضيف وسيلة دفع.

الميزات ذات الحصص ليست استخدامًا غير محدود. لا نفحص وسيلة الدفع الموجودة في حسابك ولا نغيّر ميزانيتك نيابةً عنك. إذا كانت بطاقة موجودة أصلًا، راجع حدود الإنفاق والإيقاف قبل تشغيل Codespaces أو غيرها.

## 1. GitHub Pages

- متاحة للمستودعات العامة مع GitHub Free وFree للمؤسسات.
- تستضيف **HTML وCSS وJavaScript** وملفات ثابتة. لا تشغّل Node.js أو Python أو قاعدة بيانات على الخادم.
- نطاق المشروع الافتراضي هو `https://OWNER.github.io/REPOSITORY/`. شراء نطاق مخصص غير مطلوب.
- الحجم المنشور لا يزيد على **1 GB**، وللنقل حد مرن يبلغ **100 GB شهريًا**. توجد حدود وسياسات استخدام أخرى؛ ليست استضافة بلا قيود.
- Pages ليست مخصصة أو مسموحة كاستضافة مجانية لمتجر أو معاملات تجارية أو SaaS تجاري، ولا لإرسال كلمات مرور أو أرقام بطاقات.

**في هذا المشروع:** `pages.yml` يبني الموقع ويختبره وينشر `dist` من `main` فقط. فعّل Source = GitHub Actions كما في [دليل التفعيل](ACTIVATION.md).

المصادر: [ما هي Pages؟](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [حدود Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).

## 2. GitHub Actions

- وقت **المشغّلات القياسية المستضافة لدى GitHub** مجاني للمستودعات العامة.
- في المستودعات الخاصة تحصل خطة Free على **2,000 دقيقة شهريًا** و**500 MB** تخزين مشترك بحسب قواعد الخدمة. الاستهلاك يتأثر بنظام ونوع المشغّل.
- كلمة «مجاني» لا تعني عدد وظائف متزامنة غير محدود أو إلغاء المهلات وحدود API أو التخزين والاستخدام العادل.
- تخزين Artifacts وPackages يشتركان في حصة؛ Cache لها قواعد وحصة منفصلة.
- لا تعتمد على عبارة «Actions غير محدودة» دون تحديد نوع المشغّل والحساب وحدود الخدمة.

**في هذا المشروع:** CI وPages وCodeQL تستخدم `ubuntu-latest` القياسي، مع مهلات محدودة، صلاحيات أقل، وتثبيت الأكشنات بمعرّفات commit. لا توجد مهام جمع بيانات مستمرة أو تشغيل خادم دائم. ملف النشر يحتفظ بأثر Pages لمدة يوم واحد، ولا يرفع تقارير المتصفح الكبيرة إلى Artifacts.

تتخطى الوظائف هذا المستودع إذا تغيّر إلى Private؛ تغييره يحتاج مراجعة الخطة والحدود أولًا.

المصادر: [فوترة Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions) · [الحصص حسب الخطة](https://docs.github.com/en/billing/reference/product-usage-included).

## 3. GitHub Packages وContainer Registry

- الحزم العامة مجانية في التخزين والنقل.
- للحزم الخاصة في Free: **500 MB** تخزين و**1 GB** نقل شهريًا. التخزين مشترك مع Actions Artifacts، وليس 500 MB إضافية لكل مستودع أو خدمة.
- تخزين الصور ونقلها في **GitHub Container Registry / GHCR** مجانيان **حاليًا** وفق التوثيق، مع إشعار مسبق إذا تغيّرت السياسة.
- المستودع العام لا يضمن أن حزمة جديدة ستكون عامة تلقائيًا. يجب مراجعة **Package settings → Change visibility**.
- دون وسيلة دفع صالحة، تتوقف الخدمات المعنية عند تجاوز الحصة بدلًا من استمرار استخدام مدفوع.

**في هذا المشروع:** Dockerfile وسير نشر GHCR يدوي اختياري. لا يُنشَر شيء عند رفع الكود أو الدمج. `package.json` يحمل `private: true` لمنع نشر npm غير مقصود؛ المشروع ليس مكتبة npm منشورة.

لتجربة الحاوية محليًا إذا كان Docker متاحًا:

```sh
docker build -t computer-e .
docker run --rm -p 8080:8080 computer-e
```

الصورة تشغّل Nginx غير مخوّل كمستخدم root، وتعرض ملفات ثابتة. نشر الصورة على GHCR **لا يستضيف الموقع على الإنترنت**؛ Pages هي خدمة استضافة هذا المشروع.

المصدر: [فوترة Packages](https://docs.github.com/en/billing/concepts/product-billing/github-packages).

## 4. GitHub Codespaces

- الحساب الشخصي Free: **120 ساعة نواة/شهر** و**15 GB-month/شهر**.
- الحساب الشخصي Pro: **180 ساعة نواة/شهر** و**20 GB-month/شهر**.
- 120 ساعة نواة تعادل نحو **60 ساعة تشغيل على جهاز ثنائي النواة**، أو وقتًا أقل على جهاز أكثر أنوية.
- الحصة للحساب الشخصي، وليست لكل Codespace. المؤسسات لا تحصل على الحصة الشخصية نفسها لمجرد استخدام خطة مجانية.
- إيقاف البيئة يوقف وقت المعالجة، لكنه لا يلغي التخزين؛ حذف البيئة غير المطلوبة يقلّل التخزين اللاحق.
- الصور المخصصة والإضافات والملفات تستهلك التخزين أيضًا. لذلك لا نضيف Prebuilds أو نبدأ بيئات تلقائيًا.
- دون وسيلة دفع صالحة، يُحظر الاستمرار بعد نفاد الحصة. يمكن الانتظار لتجدد الحصة أو تصدير التغييرات حسب تعليمات GitHub.
- الطالب الذي يحصل على GitHub Pro ضمن مزايا Education يمكن أن يستفيد من حصة Pro؛ لا نفترض الأهلية أو منح المزايا لكل حساب.

**في هذا المشروع:** ملف devcontainer جاهز؛ اختَر جهازًا ثنائي النواة، واضبط مهلة خمول قصيرة من حسابك، ثم أنشئ البيئة فقط عند الحاجة.

المصادر: [فوترة Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) · [الحصص حسب الخطة](https://docs.github.com/en/billing/reference/product-usage-included) · [GitHub Education](https://education.github.com/pack).

## 5. GitHub Copilot

- **Copilot Free:** مجانية للأفراد المؤهلين، وتتيح **2,000 إكمال كود شهريًا** مع رصيد محدود من **GitHub AI Credits** للمزايا الأخرى.
- التوثيق الحالي لا يقدّم رقمًا عامًا ثابتًا لكل محادثات Free؛ لذلك لا نكرر حدًا قديمًا للمحادثات أو نعد باستخدام غير محدود.
- **Copilot Student:** الخطة الحالية المجانية للطلاب المتحقق من أهليتهم. إثبات Education ثم تفعيل Copilot خطوتان منفصلتان، وتُراجع الأهلية دوريًا.
- بعض المعلمين ومشرفي مشاريع مفتوحة المصدر المعروفة قد يتأهلون لمزايا أخرى؛ هذه ليست أهلية مضمونة لكل مستودع عام.
- تفعيل Copilot يحتاج موافقة من حسابك، ولا يمكن لسير CI شراءه أو تفعيله نيابةً عنك.
- إذا ظهرت صفحة شراء أو تجربة مدفوعة وأنت تريد Free أو Student، **لا تكمل الشراء**. راجع المزايا أو دعم GitHub.

**في هذا المشروع:** تعليمات وروابط فقط. لا يتم إنشاء اشتراك أو تشغيل Copilot cloud agent أو خدمة مدفوعة.

المصادر: [خطط Copilot](https://docs.github.com/en/copilot/get-started/plans) · [تفعيل Copilot Student](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students).

## 6. GitHub Projects وIssues

المستوى المجاني متاح لكل المستخدمين ويشمل تتبع المهام وعرضها كلوحة أو جدول وربطها بـ Issues وPull Requests. لا تحتاج أداة إدارة مشاريع مدفوعة لهذا المشروع.

**في هذا المشروع:** قوالب Issues وطلب الدمج جاهزة. إنشاء Projects في حساب شخصي يحتاج صلاحيات حساب منفصلة عن رفع الكود. لا توجد لوحة فعلية لمجرد وجود هذه القوالب؛ اتبع [دليل Projects](PROJECTS.md).

المصادر: [Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects) · [المستوى المجاني لـ Issues وProjects](https://github.com/features/issues).

## 7. الأمان

- **Dependabot alerts وSecurity updates وVersion updates:** متاحة لجميع خطط GitHub، مع ضرورة مراجعة Dependency graph والإعدادات.
- **Secret scanning وPush protection:** التوثيق الحالي يذكر إتاحتهما افتراضيًا للمستودعات العامة. توجد أنماط وأسرار قد لا تُكتشف؛ الفحص لا يضمن منع كل تسريب.
- **Code scanning وCodeQL:** من الميزات المتاحة للمستودعات العامة مجانًا. المشروع يحتوي على سير CodeQL لـ JavaScript.
- **Private vulnerability reporting:** يُفعّل من المالك لتلقي بلاغات ثغرات سرية.
- ليست كل ميزات GitHub Secret Protection أو GitHub Code Security مجانية لكل أنواع المستودعات. لا نطلب شراء Advanced Security لهذا المستودع العام.

**في هذا المشروع:** سير CodeQL، إعداد Dependabot، سياسة SECURITY، وتثبيت الأكشنات إلى commit بدلًا من الاعتماد على وسم قابل للتغيير. لا نخزّن مفاتيح سرية. مراجعة الإعدادات من المالك ضرورية لأن حالة الحساب لا تُستنتج من الملفات.

المصدر: [ميزات الأمان وتوافرها](https://docs.github.com/en/code-security/getting-started/github-security-features).

## 8. التنبيهات والميزانيات

- يمكن تفعيل تنبيهات الحصة المضمَّنة عند **90% و100%**.
- ميزانيات الإنفاق لها تنبيهات عند **75% و90% و100%** من الميزانية المحددة.
- تنبيه البريد **ليس** إيقافًا للاستخدام. راجع خيار **Stop usage when budget limit is reached** إذا كانت وسيلة دفع موجودة في الحساب، واضبط منع الإنفاق الإضافي بحسب ما تسمح به واجهتك.
- لا نضيف بطاقة ولا نغيّر ميزانية المستخدم أو نفترض أن البطاقة غير موجودة أصلًا.

المصدر: [إعداد الميزانيات والتنبيهات](https://docs.github.com/en/billing/how-tos/set-up-budgets).

## 9. GitHub Skills

[GitHub Skills](https://skills.github.com/) منصة دروس عملية مجانية. ابدأ بـ Introduction to GitHub، ثم GitHub Pages وActions. التمرين لا يعفيك من حدود خدمة تستخدمها أو قواعد عدم نشر أسرار وبيانات خاصة.

## ما تغيّر عن الدليل الأول؟

1. صياغة Actions أصبحت **«وقت المشغّلات القياسية مجاني للعامة»**، وليست وعدًا بإلغاء جميع الحدود.
2. Codespaces تُقاس بـ **ساعات النواة** وبـ **GB-month** للتخزين، مع توضيح الفرق عن ساعات التشغيل.
3. مزايا الطلاب الحالية تذكر **Copilot Student**، ولا تعد كل طالب بـ Pro تلقائيًا.
4. أُضيفت ملاحظة أن تخزين Packages وActions مشترك، وأن الحزمة العامة لا تنتج تلقائيًا عن مستودع عام.
5. أُضيفت حدود Pages وطبيعتها الثابتة، والفرق بين **ملفات جاهزة** و**تفعيل فعلي** و**نشر ناجح**.
6. أُوضِح أن تنبيهات الفوترة وحدها لا تمنع الإنفاق إذا كان الحساب يحتوي على وسيلة دفع.
