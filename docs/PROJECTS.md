# إعداد لوحة Computer-e على GitHub Projects

Projects وIssues يقدّمان مستوى مجانيًا. قوالب المهام موجودة، لكن اللوحة تحتاج إنشاءً من حساب له صلاحيات Projects؛ رفع ملفات المستودع لا ينشئ لوحة تلقائيًا.

## الإعداد من المتصفح

1. افتح [Projects في حساب المالك](https://github.com/users/celiaelazamey-arch/projects).
2. اختر **New project → Board** وسمّه **Computer-e**.
3. استخدم حالات **Todo** و**In progress** و**Done**.
4. أضف عرض **Table** إذا أردت ترتيب المهام أو تصفيتها.
5. من تبويب **Projects** في المستودع، اربط اللوحة الجديدة به.
6. أضف Issues وPull Requests عبر **Add item** أو من صفحة المهمة نفسها.
7. من إعدادات **Workflows** في اللوحة، اضبط نقل المهمة إلى Done عند إغلاق Issue أو دمج Pull Request. راجع السلوك الملائم للفريق بدلًا من افتراض تفعيله تلقائيًا.

## مهام بداية مقترحة

| المهمة                             | الحالة المقترحة | معيار الإنجاز                                 |
| ---------------------------------- | --------------- | --------------------------------------------- |
| تفعيل Pages ودمج ملفات الإعداد     | Todo            | نجاح deploy وفتح رابط الموقع                  |
| مراجعة إعدادات Security            | Todo            | مراجعة Dependabot وفحص الأسرار وحماية الرفع   |
| تخصيص محتوى الموقع                 | Todo            | تحديث النصوص، نجاح CI وإمكانية الوصول         |
| تجربة Codespaces ثنائية النواة     | Todo            | تشغيل المشروع ضمن الحصة، ثم إيقاف/حذف البيئة  |
| مراجعة مصادر الحصص المجانية دوريًا | Todo            | تحديث تاريخ المراجعة والنصوص عند تغير التوثيق |

هذه قائمة مقترحة وليست Issues أو لوحة أُنشئت بالفعل.

## القوالب المرفقة

- `.github/ISSUE_TEMPLATE/bug_report.yml`: خطوات إعادة المشكلة والنتيجة المتوقعة وبيئة المتصفح.
- `.github/ISSUE_TEMPLATE/feature_request.yml`: وصف الميزة والقيمة المطلوبة.
- `.github/pull_request_template.md`: التغييرات والاختبارات ومراجعة الأمان والتكلفة.

لا تُرسل كلمات مرور أو رموز وصول أو بيانات خاصة في Issues عامة. للإبلاغ عن ثغرة، اتبع [SECURITY.md](../SECURITY.md).

المصدر: [توثيق Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects).
