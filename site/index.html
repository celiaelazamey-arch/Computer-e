04 / قبل الانطلاق

أسئلة في محلها.

إجابات قصيرة، عشان تبدأ وأنت مطمئن.

هل النشر يحتاج فيزا أو بطاقة بنكية؟

هذا الإعداد يستخدم GitHub Pages لمستودع عام ومشغّلات Actions القياسية المجانية، ولا يطلب بطاقة. استخدم نطاق github.io المجاني، ولا تبدأ تجربة اشتراك مدفوع أو تضف خدمات خارجية مدفوعة.

هل تم تفعيل كل شيء بمجرد إضافة الملفات؟

لا. ملفات الموقع والاختبارات وCodeQL وDependabot وCodespaces جاهزة، لكن Pages وإعدادات الأمان تحتاج مراجعة صلاحيات المستودع. Copilot وProjects يحتاجان تفعيلًا من حسابك. لا تعتبر الموقع منشورًا حتى تنجح مهمة deploy.

هل يمكن تشغيل Backend أو قاعدة بيانات على Pages؟

لا، Pages تستضيف ملفات ثابتة فقط. هذا الموقع لا يحتاج Backend أو قاعدة بيانات. إنشاء خادم أو تسجيل دخول أو معالجة مدفوعات يحتاج تصميمًا وخدمة أخرى، مع مراجعة شروطها وحدودها المجانية.

ماذا يحدث عندما تنتهي الحصة المجانية؟

بدون وسيلة دفع يتوقف استخدام Codespaces وPackages حتى تجدد الحصة أو تتغير الإعدادات. أوقف Codespaces عند عدم استخدامها واحذف البيئات القديمة. إذا كان الحساب يحتوي على وسيلة دفع، راجع حدود الميزانية والإيقاف الصريح بدلًا من الاعتماد على التنبيهات فقط.

هل يحصل أي طالب على Copilot Pro تلقائيًا؟

لا. يجب التحقق من الأهلية عبر GitHub Education ثم تفعيل الميزة. التوثيق الحالي يذكر Copilot Student كخطة مجانية للطلاب، وليس اشتراك Pro تلقائيًا. إذا ظهرت صفحة شراء، لا تكملها؛ راجع حالة المزايا أو دعم GitHub.
